# DigitalLiquid App

Native Android Kotlin prototype for a floating Dynamic Island-style overlay.

## Build
GitHub Actions workflow: **Build DigitalLiquid Debug APK**.

## Permissions
- Display over other apps: required for the floating island.
- Notification access: optional, used to read notification/media metadata.
- Foreground service notification: shown while the overlay runs.

This is a starter prototype. Media playback controls, complete notification cards, and vendor-specific battery/background behavior require further implementation and device testing.
